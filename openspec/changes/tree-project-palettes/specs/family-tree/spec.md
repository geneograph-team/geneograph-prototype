# ADDED Requirements

### Requirement: Staged Tree settings sidebar
Tree Settings SHALL offer Visibility, Coloring and Palette sections in the existing settings-sidebar pattern, with persistent Apply and Cancel actions. The Visibility section SHALL use Show extended family for the existing collateral visibility rule. The Palette section SHALL show all sixteen slots, their reference-relative paths and origins, separate enabled/inactive indicators and missing origins, and theme-specific editing and reset controls. There SHALL be no standalone canvas legend. Switching sections SHALL preserve unsaved edits; dismissal SHALL discard them.

The Visibility section SHALL allow changing the actual project default person through the same person selector as Coloring. The selection SHALL be staged until Apply, validated against the current project, and SHALL NOT implicitly change current focus or branch reference. The branch reference field SHALL explain that colors follow that person's ancestors.
