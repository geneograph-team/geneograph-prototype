# Design

Automatic matching uses a project-scoped name shortlist and prepares dates on demand. The original score and eligibility checks still decide the result. Manual selection continues to search the full eligible population.

The review prepares Tree-side board records and internal IDs for relevant families on demand. Plan diffing uses ID lookups and compares touched canonical records. Search, filtering, people navigation, and summary display can reuse a single draft-local plan. Apply builds a fresh projection and checks the current records before writing.

Board rendering batches card text-fit geometry reads between class updates. The editor retains its existing canvas and inspector render lifecycle.
