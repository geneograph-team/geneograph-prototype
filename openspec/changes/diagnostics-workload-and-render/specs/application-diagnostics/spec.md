## MODIFIED Requirements

Detailed Diagnostics SHALL report page-wide long tasks for both selected and entire-application recordings where supported. Excluded module operations remain excluded from the samples.

## ADDED Requirements

Schema 3 SHALL provide bounded epoch-level outcomes and latency histograms independent of the rolling operation samples. Detailed operation samples SHALL distinguish sync phase coverage and remainder from frame opportunities and image element observations. Albums workload context SHALL contain only aggregate counts and known size metadata. See the recording protocol for field definitions and browser limitations.
