# Design

Founder follow-up: prioritize recall and accept the first plausible provider-ranked result when ambiguous. Shared query preparation and response language depend on the input, not interface language. Match literal/alias names, transliteration and bounded spelling variants; allow a provider-only name with strong settlement-level score and corroborated complete geographic context. Explicit contradictory country, reliably incompatible settlement type, invalid coordinates, and comparable administrative conflicts remain exclusion criteria; missing optional metadata, low overall address confidence, and a full pool do not veto a plausible result. Settlement-level score takes precedence for provider-only results. Keep the previous strict verifier solely for automatic merge identity: ambiguous/weak/provisional placement has no merge evidence. Retain session-local diagnostics with selected name and available scores; provisional assignments have an inspector note. No automatic cross-provider retry; manual fallback unchanged.

At job completion reconcile two unchanged newly enriched records only with shared provider identity, exact matching coordinates, compatible geography/type, no authored conflicts or dismissal. Use canonical merge and preserve selection/project ownership; more specific name wins. One-sided coordinate/name pairs are review suggestions, not proof. Verified evidence is session-only and can be reused after an explicit single-place retry if both records remain unchanged. Each merge refreshes the survivor snapshot before further same-identity reconciliation. If active inline editing or a Geneograph canvas makes an unattended reference remap unsafe, leave the pair for manual review rather than holding the lookup status open. Diagnostics are session-local and explicit retry is a one-place job using existing scheduling. No data schema change. Numerical fixtures do not establish actual live provider behavior.
