# Design

Reuse the accepted immutable Tree default bases and gamut-bounded tonal generator via the existing classic-script load order. Cache only the 21 immutable default recipes per theme as needed; do not read project palette preferences or ancestry. Inherited neutral/male/female/unknown board presets use detail fills, detail outlines and dark foreground; shapes inherit the shared green recipe. Board-specific and node-specific paint flags, colors, alpha, visibility and geometry stay unchanged. Inherited text may select contrasting ink against the effective composited background if necessary, while explicit default or node text remains authoritative. Decorative initials tiles use the shared avatar tone for default fills, otherwise derive a distinct tone and contrast-selected initials from actual composited fill. Selection keeps the board outline and does not recolor cards or initials tiles. Render, live paint updates and thumbnail previews use the same resolved paint logic; PNG capture clones rendered stage. Apply inherited theme colors on editable import. Picker uses 16 shared theme-specific hues, neutral and semantic swatches; clicking stores literal color, not a branch assignment or theme link. No schema changes or new dependencies.
