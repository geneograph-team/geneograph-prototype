# Delta: Geneograph board theme defaults

## ADDED Requirements

### Shared graph palette

Inherited Geneograph person gender/neutral appearance SHALL use the accepted Family Tree category recipes for the effective theme, with readable foregrounds and distinct initials-only tiles. Inherited shape colors SHALL use the shared heritage-green recipe. Manual color suggestions SHALL expose the shared theme palette and neutral/semantic colors without automatic branch assignment or dependence on mutable Tree project palettes. Explicit paints, alpha, disabled paint, loaded portraits, selection and board editing SHALL remain independent. Inherited text SHALL adapt to insufficient contrast where possible without rewriting authored text paints. Existing preview and export paths SHALL use the resolved board appearance.
