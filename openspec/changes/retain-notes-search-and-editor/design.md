# Design

Prepare linked-resource labels and person search fields on demand by project and language. Read note body, title, checklist, tags, related titles, collection membership and source-link membership from current records for each query. Preserve existing search and eligibility rules.

Keep the active writing pane connected and update its surrounding UI for compatible renders. A different record, changed editor content or language, a closed editor, or leaving Notes releases the editor through the established lifecycle. Note-body changes refresh the excerpt and notify the notes domain. Deferred selection restoration checks the rendered browser pane before running.
