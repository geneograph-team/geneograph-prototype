# Design

Derive sRGB tones from each editable base via OKLab lightness and proportional chroma-axis scaling with bounded gamut mapping. Detail uses a single tinted surface, not a nested panel. Dark full detail targets OKLab L 0.405; light targets 0.945. Compact/actions gradually approach overview, bounded to preserve secondary-text contrast. Label/marker share the overview fill and label ink is selected from that actual fill. Outline and connector tones are derived independently from their assigned channels. Both themes are generated once per palette object on the Tree shell; CSS theme and detail selectors choose tones. Existing palette storage, branch resolution, selection, focus and layout are unchanged. The exact default palette and lightness targets are design candidates subject to founder visual review.
