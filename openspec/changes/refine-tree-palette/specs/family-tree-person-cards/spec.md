# Delta: Family Tree person cards

## ADDED Requirements

### Theme-specific category tones

Each of the twenty independently editable category base colors per theme SHALL derive readable overview, intermediate and detailed card tones with preserved hue where chromatic, plus outline and connector tones. Light mode SHALL use bright pastels and dark mode SHALL use clear tinted detailed surfaces. Label ink SHALL be derived from the actual overview fill. The fill, outline and connector channels SHALL remain independent. Theme or semantic zoom changes SHALL NOT change slot assignment, stored base colors, geometry or selection. New defaults SHALL apply to missing/invalid values and explicit resets without overwriting stored valid colors.
