# Design

Use the current project's canonical person record, not the directory summary, for attributes. Render only meaningful recorded values, in stored order within each type. Keep author text escaped and fully wrapped. The card is read-only and the existing Edit profile action remains its edit path.

The facts card has a minimum height and natural content height. On desktop the lower grid row follows that card while Relatives stretches within the row and scrolls internally. On narrow layouts each card sizes independently.
