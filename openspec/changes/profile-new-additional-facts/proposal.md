# Profile New additional facts

## Why

The Overview's right-hand card is empty despite recorded biographical attributes. Issue 195 defines a grouped read-only presentation of those values and a growing card layout.

## What changes

- Show the selected person's recorded alternative names, religion, occupations, education, custom facts, and cause of death in fixed group order.
- Show the recorded maiden name in the Profile New hero.
- Let the facts card grow with its content; keep Relatives scrollable at the resulting desktop row height.
- Keep legacy Profile, editing, Timeline, resource tabs, and stored data unchanged.
