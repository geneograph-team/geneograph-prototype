# Design

Generate a small static script in the copied artifact from the actual checkout. Select the nearest reachable strict numeric version tag by revision distance; break ties by descending numeric version. Treat no tag as development, no generated identity as local. Normalize once in the runtime before About and Diagnostics; never fetch remote state. Display and copy one combined version/short SHA string; keep the full SHA and channel in Diagnostics only. Use an accessible icon-only copy action in the Version row, shared text links for external About destinations, a normal button for the product tour and a status-only Help center row. Use the existing toast and a selectable text fallback for denied clipboard access. The existing workflow's branch/path triggers remain unchanged; tag-only pushes do not deploy. See README for full policy.
