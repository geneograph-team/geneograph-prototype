# Why

Issue 193 advances the parallel Profile New view by replacing its empty Timeline shell with real, chronological person events. The founder selected a dialog for event details, edit actions, evidence files, and citations so the fixed-height horizontal Timeline remains readable.

# What Changes

- Render all project-scoped events for the selected person in a horizontal track, using the existing event sort, icon, color, date, age, detail, and evidence helpers.
- Keep year and derivable age above the track, semantic marker on it, and title/details below.
- Open the established full event renderer and its working actions in a scrollable event-details dialog.
- Provide horizontal controls and keyboard access, without an internal vertical Timeline scrollbar.

# What Stays Outside Scope

Legacy Profile, Family Tree Timeline, other Profile New panels/tabs, event storage, and evidence models.
