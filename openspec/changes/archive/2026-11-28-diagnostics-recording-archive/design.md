# Design

The shell uses stable state-driven controls and the existing nested confirmation modal. Recorder epoch identifies retained/exported results; generic start appends, UI validates and confirms before clear/start. Selected modules default empty independently of entire-application scope. Export success means download initiation only.

Archive instrumentation uses the existing operation ring and current epoch. Layout/presentation/render path fields and fixed numeric counters/stages are optional in schema 3. Layout: details/icons/image/sources. Presentation: desktop/mobile/viewer/sources (current viewport breakpoint and layout; counts include hidden variants). Path: full/partial/hydrate/observe. Folder navigation and layout switch time actual render boundaries; scroll on the ordinary file list is a sampled observation, not measurement of native scrolling. Existing viewer strip/resize work is sampled at most once per 120 ms per kind. Native frame opportunity is not paint.

`archivePerformance.layouts` groups task categories by source field: original, preview, thumbnail, derived or unknown. Source categories describe the selected field, not proof of actual resolution. Started/pending/maxPending, completed/failed/canceled and elapsed totals/max measure observed tasks. DOM load observation starts after insertion (cached elements can already be complete); elapsed is not pure decode, network time or paint. Existing mounted, incomplete images are observed from Start with unknown provenance unless available; already completed images from before Start are not counted as new requests. Native image loading is not forced; no extra decode or fetch. Explicit viewer decode and thumbnail generation measure real existing operations. Loaded natural dimensions count observations including repeated images; not a count of unique assets. Mounted and completed element counts are not viewport visibility. File bytes are metadata for matching image candidates with known size; absent size data is omitted.

Existing Image-view load cache and thumbnail generation are instrumented without changing their policy. Thumbnail encoded bytes count existing base64 JPEG payloads, estimated decoded bytes are loaded viewer-cache natural pixel dimensions times four, not actual resident browser memory. Future #456 calls `archiveMetric` for previewJobsQueued/Canceled, sourceBytesObserved/Samples, thumbnailCacheHits/Misses/Evictions, pendingJobs/runningJobs, thumbnailEntries/thumbnailEncodedBytes/estimatedDecodedBytes (last/max gauges), resizeMs/encodeMs/queueWaitMs (total/max/calls); async callers use `archiveTaskBegin`, `archiveTaskValid` and `archiveTaskFinish` to prevent stale epoch attribution. No new thumbnail cache, scheduler, or asset mutation is added by #506. Preview hydration stage/counter hooks are available for #456 when actual work exists. Unavailable data is absent, not zero.

DOM observation is capped at 2,048 pending elements with skipped count, canceled on replacement/Stop/exit. Cancellation means observation ended; application image requests are not changed. Explicit tasks that are unfinished at Stop remain pending; later completion is excluded by epoch checks. Basic/disabled/excluded mode installs no image observations. Entire application + Detailed remains required for page-wide long tasks; no per-operation attribution. No IDs, URLs, file names, queries, raw browser entries or image bytes exported.

The selected-module checklist exposes the eight currently available modules, excluding unreleased Publish. Preserve Publish in the internal operation allowlist and entire-application instrumentation. Select all selects only the eight available modules. The native fieldset is borderless and accessibly named without a repeated visible legend.


Final visual refinement: compact configuration grid and token-backed raised checklist surface with shared checkbox markup, no inherited per-row top margin, 32px minimum row height, concise inline module caption and bulk actions, selected-mode help beside its label, one configuration/status divider, and visually muted disabled Start/New recording. Retain label-above-value metrics and all recording/export lifecycle behavior. Approximate height reduction is a design objective, not a measured result.
