# Design

Keep one normalized 20-color palette per theme in the existing per-project display preferences: 16 branch slots, male, female, unknown and neutral. Valid values are six-digit hex; missing/invalid values fall back to former theme defaults. All slots persist independent of branch count. The defaults are owned by treeDisplaySettings helpers; the runtime writes both themes as shell-local CSS variables, so theme changes resolve via CSS without a new layout. Neutral applies to normal/partner connectors, outline and card tint; the existing 13/25/90/99% semantic fill strengths are retained, including neutral tint in detailed view. Selection/focus remain separate. Label ink is chosen from black/white based on category luminance. No change to zoom thresholds.

The settings form uses Visibility, Coloring and Palette sections in a viewport-bounded sidebar layout. Mounted hidden sections preserve draft form state; palette editing selects light/dark without switching the application theme. The existing branch graph and origin traversal provide all sixteen paths, with separate preset inclusion and missing-origin labels. The graph is prepared lazily once on opening Palette. Reset color, current theme, or both themes operates only on the draft. Apply normalizes and commits once; only visibility changes use the existing geometry path. Native validation of an invalid control in a hidden section reveals that section before the browser focuses the field. The shared modal lifecycle owns initial focus, dismissal and return focus; Visibility navigation is the initial focus target. The mobile modal body stays fixed and the main panel scrolls. Cancel/dismiss does not commit. Remove canvas legend DOM, styling and update function. #451 is integrated to avoid an interim placeholder.

Founder layout refinements: Visibility shows the actual project default person (editable selector), not the transient focus. Coloring keeps the existing reference combobox and remove action but renders selected identity with the shared avatar preview. Palette lists gender/neutral first, omits the redundant reference heading, and explains inclusion via a focusable tooltip. Reuse Geneograph's HSV/hex/preset picker through a caller-owned color-only draft adapter; no board snapshot, history, storage or live Tree repaint. Close or section/theme changes dispose the picker; Escape cancels the current interaction, then normal modal dismissal discards the draft.

Approved density refinement: fixed desktop modal height reduced by 15%; compact default-person selector and plain checkbox rows; matched reference preview/search as independent controls on one line (stack at narrow widths); palette uses a compact theme/reset toolbar that scrolls with the main panel, two-column gender/neutral group and compact one-column branch rows. Keep all existing draft actions and accessible controls.

Default person selection now reuses the same shared person options/preview/search as Branch reference. Applying a valid default updates the canonical project's defaultPersonId and invokes the existing project modification path once; opening, clearing a draft, Cancel and unchanged Apply do not modify the project. A project with people requires a valid same-project nondeleted default. Current focus and explicitly chosen branch reference are independent. The branch reference label has a hover/focus explanation of ancestor-relative coloring.

Approved #451 balance refinement: retain the fixed modal and left-align Visibility and Coloring within a 640px maximum content width; Palette stays full width. Use Default person and Visible generations as the Visibility headings, with the redundant field label visually hidden but accessible. Distinguish Color channels from Branch coloring, retain the reference selector, and place collateral coloring on its own full-width row with visibility-independent help. One equal-width three-column grid aligns generation inputs, coloring channels and branch count; the three channels fill the same width as both person picker rows and dividers. The grid reduces to two columns at narrow widths and one column on small screens. Keep existing controls, theme and staged behavior.

Both Tree Settings person selectors use the shared search-only combobox mode: no dropdown toggle and no unfiltered list on focus, click or empty query. Typing a nonblank query displays matching people with existing keyboard and mouse selection, selected identity, and clear action. Other shared comboboxes retain their existing dropdown behavior.
