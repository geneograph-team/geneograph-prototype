# Design

The shared shell binder accepts the native input value into the existing state key immediately and schedules at most one current refresh. Composition defers publication until commit; Tab/Enter flush before native keyboard navigation. A single pending update captures input, binding root, query and project/module/language scope; normal shell replacement or incompatible input invalidates it. A modal defers publication and closure resumes only a still-current update. The ordinary typing path never restores focus or selection asynchronously.

Consumer renderers still produce the existing complete query/filter/sort/count markup. During compatible search refresh only, the shared branch replacement preflights and retains the actual connected input and passive ancestor chain, then replaces sibling regions and updates wrapper attributes. This does not move the input through a detached fragment. Consumers rebind new controls; the retained input binding is idempotent. Notes integrates the branch update with its existing compatible editor retention; selection exclusion still closes the editor. Places keeps existing map host/status leaves connected during a compatible search. Non-search renders retain existing replacement behavior. Albums grid work remains #457. Album folder browser uses its existing in-place filter, not this binder; shared resource pickers are unchanged. All audited main-view binders use the shared path; Publish home integration is not a claim that the disabled feature is available.
