# Proposal

## Why

People needs a parallel Profile New layout for review without disrupting the working Profile.

## What Changes

- Add Profile New beneath Profile, sharing the active project and selected person.
- Add six working tabs and empty Timeline, Relatives, and Facts & connections cards.
- Retain legacy Profile as the destination for all existing entry points.

## Capabilities

### New Capabilities

- `people-profile-new-shell`: the localized, accessible parallel view and its empty Stage 1 layout.

### Modified Capabilities

None.

## Impact

People view state, navigation, rendering, localization, and scoped styles only. No data or persistence changes.
