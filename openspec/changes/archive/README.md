# Archived OpenSpec changes

Changes here are **historical, not active requirements**. Current
requirements are in `openspec/specs/`.

The 2026-11-18 migration moved all 20 legacy active change folders into
dated archives and administratively closed previously unchecked tasks
on the founder's instruction. These checkmarks **do not certify** that
native test runs, deployment tests, manual browser QA, or historic
sign-offs actually happened. The archive preserves original proposals,
designs and delta specs for traceability, including superseded ones.

Future approved changes should automatically be archived once their
implementation and acceptance are complete, by the same agent/PR that
finishes the work. See `openspec/README.md` for the closeout checklist.
