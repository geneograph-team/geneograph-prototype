# Delta: GEDCOM import

## ADDED Requirements

### Verified post-import duplicate reconciliation

Automatic reconciliation SHALL be limited to unchanged newly imported settlements with independently established shared provider identity, compatible context, matching coordinates and no conflicting authored fields or dismissal. Use the canonical reference remap, preserve names as aliases, project ownership and active selection. Unverified shortened/full names SHALL remain review suggestions rather than automatic merges. Existing stale-write and asynchronous lifecycle protections SHALL remain intact.
