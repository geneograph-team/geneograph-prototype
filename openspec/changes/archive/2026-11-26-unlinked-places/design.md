# Design

Enumerate explicit canonical Place fields per owning project, including structured date fields and board-local facts, project-scoped nodes, sources and typed links. Derived events, free text and review metadata are not dependencies. Count unique authored owners; retain the existing inspector category counters. Clear/retarget using that traversal, including deleted owners for reference integrity. Unlinked review deletion checks live references immediately before commit. Unlinked Places without coordinates appear in the unlinked group instead of the missing-position group; invalid coordinates remain actionable. Count distinct affected Places across active reviews. Existing edit/render boundaries invalidate Keep decisions after a link is acquired. Preserve the single-Place dismissal shape; add only the `unlinked` type.
