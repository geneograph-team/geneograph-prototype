## ADDED Requirements

### Requirement: Prepare imported place context offline

The importer SHALL preserve authored place names and fact text, reconstruct continuations, extract unambiguous valid embedded latitude/longitude pairs, preserve valid explicit MAP coordinates and report conflicts without choosing one. Consolidate only equivalent complete place hierarchies with compatible coordinates, preserving aliases and all references. Imported records SHALL have valid timestamps. This preparation precedes automatic geocoding; existing projects SHALL NOT be rewritten.
