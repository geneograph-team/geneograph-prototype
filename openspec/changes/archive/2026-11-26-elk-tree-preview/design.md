# Design

The application shell enters and leaves the Tree module. The Tree uses canonical visibility projection, Tree renderer, viewport, inspector and commands. The ELK adapter owns request cancellation and converts detached output into card occurrences and connectors. A future Fan renderer can use canonical focus, selection and commands at the shell boundary and own its radial projection and hit testing.

The port uses the approved compound graph, balanced Brandes–Köpf placement, dynamic spacing calculation and the occurrence projection revised in #399. Distinct co-parent contexts can give a person several appearances. Their visible upstream families attach to one chosen appearance. The project-local co-parent preference can transfer that attachment. Overlapping or incomplete contexts remain unsplit with diagnostics. The shared Tree card dimensions replace the standalone dimensions in the application. The algorithm uses the original dimensions for the reference regression. Single-parent families use a card-edge connector when there is no add-parent slot. Distinct same-pair records can reuse the same physical gap with separate inline lanes. Geometry that the inline rules cannot represent uses the affected native ELK routes with a diagnostic. Inconsistent generation constraints are surfaced as a layout error with a localized Retry action that preserves the project and focus.

The ELK 0.12.1 browser bundle runs in its own local HTML document. Its interface accepts standard ELK JSON graphs with anonymous IDs, dimensions, ports and layout options. Genealogy records and app state stay in the Tree. Browser work is scheduled asynchronously through messages, including the bundled solver's non-worker execution in offline file URLs. Request ownership is checked after each response and when leaving the presentation.

## Third-party distribution

The unchanged ELK bundle is distributed as a separate graph-layout program alongside the GPL-3.0 application. Upstream elkjs 0.12.1 declares EPL-2.0 OR GPL-3.0-or-later in its package metadata and source notices; the secondary license is available subject to its terms. The programs exchange ordinary ELK layout JSON and maintain separate execution contexts. Preserve the upstream license and source references beside the distribution; exact bundled-source and notice verification remains tracked under #428.

The unchanged browser distribution and license are copied from the upstream [elkjs 0.12.1 tag](https://github.com/kieler/elkjs/tree/0.12.1) (`lib/elk.bundled.js` and `LICENSE.md`) into `src/vendor/elkjs-0.12.1/`. The Git blob IDs are `fbebd45cfd9cd1fe10c5e5165e3ba16653e129bd` and `91dd37eefbe62d3d9fb7a1e7e2c7a9a1e2cdcbcc`, respectively, verified identical after copying. No package installation or network access is needed at runtime. Upstream layout source is available from [Eclipse ELK](https://github.com/eclipse-elk/elk). Version 0.12.1 is the version used in the founder-approved standalone centering experiments.
