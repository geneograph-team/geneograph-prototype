- `src/modules/people/relationship-editor.js`: start/end event fallback tags may express historically recorded genealogy events. Determine writer/read semantics before changing.
- `src/modules/geneograph/geneograph-editor-core.js` and `geneograph-board-files.js`: distinguish persisted board normalization from necessary external `.ggboard` import conversion; avoid removing supported external-file behavior.
- `src/shared/tree-seed-model.js`: `rebuildSampleEventsAndPruneSourceLinks()` remains in People/relationship editing paths. Verify that deleting or changing events cannot silently erase unrelated valid evidence.
- `src/modules/archive/archive-inspector.js`: `documentPlaceText` legacy UI fallback remains; audit current canonical writers and correct treatment of genuine free-text place entry.
