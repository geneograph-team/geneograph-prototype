Prototype data use

This describes the prototype's technical data flows, not the full privacy policy. For website forms, Research Group contact and privacy requests, see the GeneoGraph privacy policy.

Local research

The prototype processes research records and imported files in your browser, without a GeneoGraph project storage backend. Project changes are session-based; downloads you explicitly create remain on your device. Browser storage can retain interface preferences such as language, theme, last-project information, tree display settings and tour status. You can clear site data using your browser's settings. Clearing it may reset these preferences.

External requests

  • GitHub Pages hosts the online prototype. Hosting and CDN requests can expose ordinary request metadata, including IP address and browser information.
  • Quill and MapLibre assets are loaded from jsDelivr and unpkg. The hosted map loads styles, tiles, icons and fonts from OpenFreeMap; map tile requests reflect the displayed map area.
  • Place autocomplete sends the entered place text and interface language to Geoapify and, when needed, LocationIQ. Manual place entry does not require this search.
  • If you choose to download linked GEDCOM photos, supported references trigger requests to the MyHeritage photo host (sites-cf.mhcache.com). These requests do not upload the entire GEDCOM file. Only use files and links you are permitted to access.

External providers have their own processing and retention rules. The prototype's local processing does not prevent those providers from receiving network requests. Avoid sending sensitive information in place-search text. For privacy inquiries use Contact us.

Локальная работа

Прототип обрабатывает исследовательские записи и импортированные файлы в браузере, без серверного хранилища проектов GeneoGraph. Изменения проекта относятся к текущему сеансу; файлы, которые вы самостоятельно скачиваете, остаются на вашем устройстве. В браузере могут сохраняться настройки языка, темы, последнего проекта, отображения дерева и состояние знакомства с приложением. Эти данные можно очистить в настройках браузера; при этом настройки могут сброситься.

Внешние запросы

  • Онлайн-прототип размещён на GitHub Pages. При обращении к хостингу и CDN могут передаваться обычные метаданные запроса, включая IP-адрес и сведения о браузере.
  • Ресурсы Quill и MapLibre загружаются с jsDelivr и unpkg. Онлайн-карта получает стили, тайлы, значки и шрифты от OpenFreeMap; запросы тайлов отражают отображаемую область карты.
  • При автодополнении названия места введённый текст и язык интерфейса передаются Geoapify, а при необходимости — LocationIQ. Ручной ввод места не требует такого поиска.
  • Если вы выбираете загрузку связанных фотографий GEDCOM, поддерживаемые ссылки вызывают запросы к серверу фотографий MyHeritage (sites-cf.mhcache.com). Весь файл GEDCOM при этом не отправляется. Используйте только файлы и ссылки, к которым у вас есть законный доступ.

У внешних поставщиков действуют собственные правила обработки и хранения данных. Локальная обработка в прототипе не исключает получение ими сетевых запросов. Не вводите конфиденциальные сведения в строку поиска мест. По вопросам конфиденциальности свяжитесь с нами.
